# 分镜脚本与提示词生成

将 episode-design 的蓝图转化为可执行的逐页逐格分镜脚本，
并为每一格生成适配 Nano Banana Pro 的 AI 绘图提示词。

---

## 前置检查

1. **必须存在**:
   - `comic-project/design/story/ep{N}-design.md`（最核心输入）
   - `comic-project/design/style-guide.md`（提示词模板、分格规范）
   - `comic-project/prompts/character-prompts.md`（角色锚定词）
   - `comic-project/prompts/scene-prompts.md`（场景锚定词）
2. **建议存在**:
   - `comic-project/design/world/worldbook.md`（场景视觉参考）
   - 本话涉及角色的 `comic-project/design/characters/*.md`（表情变体、服装状态、语言画像）
3. **解析参数**: 提取话数 N。无参数则询问。

如有缺失的必须文件，列出缺失项并提示用户先完成。

---

## Phase 1: 上下文加载与规范准备

静默读取所有依赖文件，准备好：

**从 ep{N}-design.md 提取**:
- 场景列表（含预估页数）
- 情绪地图（每页目标情绪和张力）
- 爽点/笑点/钩子位置
- 分镜执行备注
- 伏笔任务（含视觉呈现方式）

**从 style-guide.md 提取**:
- 提示词模板（人物格/场景格/特写格前缀）
- 分格规范（场景类型分格策略）
- AI 工具配置
- 通用负面提示词

**从 character-prompts.md 提取**:
- 每个出场角色的外貌锚定词和表情变体词

**从 scene-prompts.md 提取**:
- 每个场景的视觉锚定词

**从角色卡提取**:
- 语言画像（对白风格依据）
- 当前服装状态（根据话数）

## Phase 2: 缩略分镜（Thumbnail）

在细化之前，先做粗排——每页的格布局和大致内容。

逐页概览：

```
=== 第{页}页 ===
格数: {N}格
布局: {规整/破格/混合}
内容概要: {一句话}
对应情绪: {从情绪地图提取}
```

展示全话的缩略概览，用 `AskUserQuestion` 确认整体节奏：
- 页数分配是否合理？
- 重要场景是否在正确的位置？
- 翻页点是否利用得当？

确认后再进入逐格细化。

---

## Phase 3: 逐页逐格分镜

按场景顺序，逐页逐格设计。每一格包含：

- **格编号**: P{页}-G{格}
- **格形状与位置**: 横格/竖格/斜格/圆格/不规则 + 在页面中的位置
- **占比**: 该格占页面的大致比例
- **镜头类型**: 远景/全景/中景/近景/特写/大特写/鸟瞰/仰角/俯角
- **画面内容描述**（中文）: 2-3 句详细描述画面中的内容
- **对白/旁白/音效**: 具体文字内容
  - 对白必须符合角色的语言画像
  - 标注气泡类型（普通/思考/呐喊/耳语）
- **情绪标签**: 本格的情绪关键词

### 分镜设计原则

- **镜头语言**: 远景建立环境 → 中景展示互动 → 近景捕捉情绪 → 特写强调关键
- **视线引导**: 读者的视线从右上到左下（日式右翻）或从左上到右下（左翻）
- **节奏控制**: 格少=慢节奏（情绪、对话）；格多=快节奏（动作、日常）
- **翻页设计**: 右页最后一格制造悬念，翻页后左页第一格给出回应或反转

### 逐页确认

每完成 2-3 页后暂停，展示给用户确认，而非一口气做完整话再确认。
这避免了大量返工。

## Phase 4: AI 提示词生成

为每一格生成适配 Nano Banana Pro 的完整提示词。

### 提示词拼装规则

每格提示词 = **风格前缀** + **角色/场景锚定词** + **本格特有描述**

**人物格**:
```
{style-guide 风格关键词}, {色彩关键词}, {角色外貌锚定词}, {角色表情变体词}, {场景锚定词}, {本格动作/姿态描述}, {镜头类型}, {光线/氛围}
```

**场景格**（无人物或人物为点缀）:
```
{style-guide 风格关键词}, {色彩关键词}, {场景锚定词}, {本格特有环境描述}, {镜头类型}, {光线/氛围}
```

**特写格**:
```
{style-guide 风格关键词}, {色彩关键词}, close-up, {角色锚定词或物品描述}, {表情/细节描述}, {光线/氛围}
```

### 提示词质量检查

每格提示词生成后自检：
- ✅ 风格前缀是否来自 style-guide？
- ✅ 角色锚定词是否完整（不能遗漏关键外貌特征）？
- ✅ 场景锚定词是否与 scene-prompts 一致？
- ✅ 是否包含镜头类型信息？
- ✅ 同一场景内的光线/氛围是否连贯？
- ✅ 角色在连续格中的外貌描述是否一致？

## Phase 5: 结束状态摘要

在分镜完成后，在 script 文件末尾添加结束状态摘要，
供下一话的 `/episode-design` 使用：

```markdown
## 本话结束状态摘要

- 最后一格画面描述
- 主角当前物理位置
- 主角当前心理/情绪状态
- 各在场角色的状态
- 读者此时掌握的信息清单（对比本话开始时新增了什么）
- 本话末尾的悬念/钩子内容
- 下一话衔接点
```

- 「将提示词文件 `prompts/ep{N}-panel-prompts.md` 导入 Nano Banana Pro 开始出图」

## 修改模式

当本话分镜已存在且用户要求修改时：

1. 读取现有分镜，定位修改目标
2. 完成修改后：
   - 同步更新 script、table、panel-prompts 三个文件
   - 如修改了结束状态摘要 → 标记下一话 ep{N+1}-design.md 需更新
3. 更新 session-state.md

---

## 协作协议

1. **先粗后细** — 先确认缩略分镜的整体节奏，再逐格细化
2. **分段确认** — 每 2-3 页确认一次，避免大规模返工
3. **提示词可调** — 提示词是起点，用户可根据 Nano Banana Pro 出图效果调整
4. **一致性优先** — 同一角色在同一场景中的视觉描述必须连贯
5. **对白合角色** — 对白必须符合角色的语言画像
6. **写入前确认** — 展示完整概览，获得用户确认后才写入
