# 视觉风格指南

定义漫画的全局视觉语言——画风、色彩、分格规范、AI 工具配置——
确保所有提示词和视觉产出的一致性。

---

## 前置检查

1. **必须存在**: `comic-project/concept/comic-concept.md`（类型/题材、参考作品、单话目标页数）
2. **建议存在**: `comic-project/design/world/worldbook.md`（世界的视觉调性）
3. **检查已有**: 如 `comic-project/design/style-guide.md` 存在 → 进入修改模式

---

## Phase 1: 画风定位

引导用户确定整体画风：

- 你心目中这部漫画的画面**第一印象**是什么？
- 参考作品的视觉特点？（可以是漫画、动画、电影、游戏）
- 倾向哪种风格？
  - 日式漫画（精细线条 / 简洁线条）
  - 美式漫画
  - 欧式 BD
  - 韩式条漫
  - 独立/实验风格
  - 半写实
  - 其他

产出：
- **风格描述**（中文）
- **风格参考作品**
- **风格关键词**（英文提示词前缀，附中文翻译）
  - 示例: `manga style, detailed linework, high contrast, cinematic lighting`
    （漫画风格，精细线条，高对比，电影感光影）

---

## Phase 2: 色彩方案

- **黑白 or 彩色？**
  - 如果黑白：网点/阴影处理方式（传统网点 / 灰度渐变 / 纯黑白高对比）
  - 如果彩色：
    - 主色调（整体画面倾向什么色调）
    - 辅色调
    - 禁用色（哪些颜色绝对不用）
    - 是否有特殊用色规则（如：只有某个角色/场景用红色）

产出：
- **色彩关键词**（英文，附中文翻译）

---

## Phase 3: 线条与技法

- **线条风格**: 粗线 / 细线 / 变化线 / 均匀线
- **清晰度**: 精致锐利 / 柔和模糊 / 手绘质感
- **阴影处理**: 平涂 / 渐变 / 网点 / 交叉线
- **特效线规范**: 速度线、集中线、情绪线的使用原则
- **文字气泡规范**: 对白气泡、旁白框、音效字体的风格

---

## Phase 4: 页面与分格规范

- **页面尺寸**: B5（182mm × 257mm）/ A4 / 条漫（长条）/ 自定义
- **出血区设定**
- **每页典型格数范围**（如：4-6 格/页为常态）
- **分格风格倾向**: 规整网格式 / 自由破格式 / 混合

**场景类型分格策略**:

| 场景类型 | 格数倾向 | 格形状倾向 | 说明 |
|----------|---------|-----------|------|
| 安静对话 | 4-5 格 | 规整横格 | 节奏稳定，聚焦表情 |
| 动作场面 | 3-4 格 | 斜格/破格/跨页 | 强调动势和冲击 |
| 情绪高潮 | 1-2 格 | 大格/整页/跨页 | 留白，让情绪呼吸 |
| 日常过渡 | 5-6 格 | 小格混排 | 快速推进，不恋战 |

- **跨页使用原则**: 什么情况下允许跨页大图
- **留白使用原则**: 什么情况下允许大面积留白

## Phase 5: AI 工具配置（Nano Banana Pro）

这是本 skill 的关键产出之一——为后续所有提示词生成提供标准化配置。

### 基础配置

- **主用工具**: Nano Banana Pro
- **推荐模型/风格预设**: （根据用户选择的画风推荐）
- **推荐参数**:
  - 图片尺寸/比例（匹配页面尺寸）
  - 其他工具特定参数

### 角色一致性方案

角色视觉一致性是 AI 漫画的核心挑战。引导用户确定一致性策略：

- **角色参考图**: 是否为每个角色生成参考图集（正面/侧面/3/4视角）？
- **锚定词策略**: 每个角色的核心外貌描述词（从 character-prompts.md 提取）
  作为每格提示词的固定前缀
- **风格锚定**: 通过统一的风格前缀保证画面风格一致
- **一致性验证**: 建议在正式出图前先为每个角色生成测试图，
  确认锚定词能稳定产出一致的角色形象

### 通用负面提示词

根据画风定义不需要的元素：
- 示例: `blurry, low quality, deformed hands, extra fingers, watermark, text`
  （模糊，低质量，变形的手，多余手指，水印，文字）

## Phase 6: 提示词模板

定义三类全局前缀模板，供 `storyboard` skill 在生成逐格提示词时使用：

### 人物格前缀
```
{风格关键词}, {色彩关键词}, {角色锚定词}, [本格特有描述]
```

### 场景格前缀
```
{风格关键词}, {色彩关键词}, {场景锚定词}, [本格特有描述]
```

### 特写格前缀
```
{风格关键词}, {色彩关键词}, close-up, {角色锚定词/物品描述}, [本格特有描述]
```

每个模板提供完整示例。

## 修改模式

当 `style-guide.md` 已存在且用户要求修改时：

1. 读取现有文件，定位修改目标
2. 完成修改后，输出「变更影响清单」：
   - 若修改了风格关键词/提示词模板
     → 标记所有已生成的 panel-prompts 需重新生成
   - 若修改了分格规范
     → 标记所有已完成的 storyboard 的分格方案需复查
   - 若修改了 AI 工具配置
     → 标记所有提示词文件需要适配新配置
3. 更新 session-state.md

---

## 协作协议

1. **视觉优先** — 用画面语言而非技术术语与用户沟通
2. **示例驱动** — 每个决定都配提示词示例，让用户直观理解效果
3. **实用导向** — 风格指南的目的是让提示词生成有章可循
4. **可迭代** — 风格指南会随着出图测试不断调整，不追求一次完美
5. **写入前确认** — 展示完整草稿，获得用户确认后才写入
