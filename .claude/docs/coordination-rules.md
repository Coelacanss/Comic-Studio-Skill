# Agent 协调规则

1. **垂直委托**: `story-architect` 委托给部门主管 agent，部门主管委托给具体任务。
   不跳级处理复杂决策。

2. **水平咨询**: 同级 agent 可互相咨询，但不得在对方领域做出约束性决策。
   例：`art-director` 可以向 `character-designer` 询问角色外貌细节，
   但不能修改角色的内心引擎。

3. **冲突解决**: 当两个 agent 意见不一致时，升级到共同上级。
   创意冲突 → `story-architect`；视觉冲突 → `art-director`。

4. **变更传播**: 当设计变更影响多个领域时，执行修改的 skill 负责：
   - 输出「变更影响清单」
   - 同步更新直接关联文件
   - 在 session-state.md 中登记待同步的下游文件

5. **文件所有权**: Agent 不得修改其职责范围外的文件，除非有明确的委托指令。

6. **用户最终决策**: 所有 agent 的输出都是建议，用户拥有最终决定权。
   Agent 应提供选项和分析，不做单方面决策。
